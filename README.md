# Por Fin Apto

App web instalable (PWA) para preparar el examen teórico de todos los permisos de conducir de España: AM, A1, A2, A, B, B+E, C1, C1+E, C, C+E, D1, D1+E, D y D+E.

Método: diagnóstico con las preguntas que más se fallan, emboscadas con repetición espaciada de tus fallos, análisis de por qué fallas y simulacros adaptativos.

- Funciona sin conexión y no recoge datos: el progreso se guarda en el dispositivo.
- App no oficial. No está afiliada a la DGT ni a ningún organismo público. Información oficial en https://www.dgt.es

## Publicación

Esta carpeta se sirve tal cual con GitHub Pages (rama `main`, carpeta raíz). Al cambiar cualquier archivo, sube el número de versión de `sw.js` (`pfa-v2` → `pfa-v3`…) para que los móviles descarguen la versión nueva.
