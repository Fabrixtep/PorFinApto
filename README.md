# Por Fin Apto

Web para preparar el examen teórico de todos los permisos de conducir de España (AM, A1, A2, A, B, B+E, C1, C1+E, C, C+E, D1, D1+E, D y D+E).

- `/` — portada.
- `/guia/` — 23 guías del teórico, agrupadas por tema, con preguntas de práctica.
- `/test/` — una página por examen (común B, AM, moto, camión, autobús y remolque): formato, temario, trampas típicas y preguntas de prueba.
- `/app/` — el test: diagnóstico, repetición espaciada de tus fallos y análisis de por qué fallas. Instalable y sin conexión; el progreso se guarda en el dispositivo.

Web no oficial. No está afiliada a la DGT ni a ningún organismo público. Información oficial en https://www.dgt.es

Se publica con GitHub Pages desde la rama `main` (carpeta raíz). Los archivos de esta rama se generan automáticamente; el código fuente (preguntas, guías y generadores) está en la rama `fuente`.
